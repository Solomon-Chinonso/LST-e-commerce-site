# LST-e-commerce-site
# E-Commerce Web Application

A modern, responsive e-commerce application built with React, TypeScript, and Redux Toolkit. This project features a full product store, dynamic layouts based on Figma specifications, and state-driven shopping capabilities.

---

##  Tech Stack

* **Frontend:** React, TypeScript, CSS Modules
* **State Management:** Redux Toolkit
* **Data Fetching & API Integration:** RTK Query
* **Icons:** React Icons
* **UI & Responsive Layouts:** Flexbox & CSS Grid

---

##  Features & Implementation

* **Responsive Design System:** pixel-perfect alignment based on design specifications across mobile, tablet, and desktop viewports.
* **Global State Management:** Redux Toolkit handles client-side state (cart, user preferences, and UI toggles) cleanly with slices and type-safe reducers.
* **API Integration & Caching:** RTK Query abstracts network calls to manage product data fetching, automatic caching, loading, and error states without boilerplate code.
* **Interactive UI:** Dynamic hero sections, interactive category cards, and responsive CTA/Footer components.
